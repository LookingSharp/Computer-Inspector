# Computer Inspector

Computer Inspector will provide scripts and tools to help inspect a machine for
malware.

## Working agreement

The authoritative behavioral specification is
[`specs/Project-Spec.md`](specs/Project-Spec.md).
All implementation and tests must conform to it.

[`AGENTS.md`](AGENTS.md) defines the repository's operating policy for coding
agents, including the speclet workflow for proposed behavior changes.
[`TEAM.md`](TEAM.md) defines the review roles for product, engineering, and
security decisions.

Notable project changes are recorded in [`CHANGELOG.md`](CHANGELOG.md) in
accordance with Keep a Changelog and Semantic Versioning.
